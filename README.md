KCI Geometry Engine: Technical Architecture & Diagram GuideThe KCI Parametric Slicer bridges raw, unorganized 3D mesh point clouds and mathematically smooth, CAD-ready parametric $B-Splines$. When a user sets values in the graphical interface, those numbers directly alter the behavioral boundaries of the KCI Continuity Interpolation Engine ($SKSI$).Below is the definitive engineering explanation of how the UI settings translate to the geometric path-planning diagram.📐 Algorithmic Mapping: UI Fields to Geometric Engine Logic1. Corridor Tolerance ($W$ - mm)UI Application: Defines the spatial slice window thickness distributed equally on both sides of the target cutting plane.Engine Mechanism: Acts as the initial 3D spatial filter. All unstructured mesh vertices falling within $\pm W/2$ of the slicing plane are captured and projected onto a unified 2D plane. This converts a thick 3D "slice" of points into a clean 2D mathematical coordinate pool.2. Max Search Radius ($R$ - mm)UI Application: Controls the tracking step limit for vector generation.Engine Mechanism (Green Dashed Circle): Represented in the diagram as the outer Yarıçap ($R$) perimeter centered around the Active Node ($P_{aktif}$).Chain Continuity: The engine will only look for candidate nodes within this circular boundary. If a structural void or casting flaw exceeds this radius, the engine halts the current spline segment cleanly, scans across the gap, locates the next nearest global point, and initiates a brand-new sub-spline without locking up.3. Suppression Distance (mm)UI Application: Defines the minimum allowable step resolution between successful spline knots.Engine Mechanism (Red Dotted Circle): Represented as the Baskılama Alanı ($min\_step$) boundary.Anti-Wobble Filtering: High-density 3D scanning produces dense clusters of noisy points. Any candidate vertex that falls inside this red suppression zone is designated as a Baskılanan/Elenen Parazit Nokta (Suppressed Noise Point) and is permanently skipped. This feature guarantees that the final curve remains pürüzsüz (perfectly smooth) and avoids erratic waviness.4. Slicing Axis & Angular RealignmentUI Application: Evaluates tracking vectors dynamically based on $X, Y,$ or $Z$ plane sorting.Engine Mechanism (Vektör Modeli): When moving from the current Active Node ($P_{aktif}$) to the next point, the engine does not blindly select the closest coordinate. It calculates the dot product between the previous path trajectory—$v_{eski}$ (Directional Trend)—and all prospective candidates.Vector Criteria:Any candidate causing a sudden, non-tangential sharp bend (e.g., an angle $> 90^\circ$ relative to the trajectory) is flagged as an Elenen Aday (Eliminated Candidate).The engine selects the node that optimizes the formula:$$\max(\cos\alpha) \quad \text{where} \quad \Delta d \ge r_{min}$$This selected point becomes $P_{yeni}$ (New Node with Smallest Angular Deviation), enforcing $C^1$ Tangent Continuity across the entire geometric chain.🧭 Real-World Edge Case: Gap Bridging on Mechanical MeshesOn industrial parts featuring mounting holes, severe drop-offs, or un-scanned regions (labeled as boşluk on mechanical scan views):Chain Termination: As the engine tracks along the boundary, it reaches a threshold where the distance to the next mesh vertex exceeds the Max Search Radius ($R$).Safe Branch Interruption: Rather than experiencing an algorithm lockup or generating a distorted, elongated line across the void, the engine cleanly finishes the active $B-Spline$ array.Dynamic Restart: The unvisited coordinate array is reassessed. The engine locates the true physical boundary on the opposing side of the void (labeled as burdan devam etmeli), designates it as a fresh start node, and seamlessly commences an independent, tangent-continuous sub-spline.This elegant combination of vector filtering and proximity-suppression criteria is what allows the KCI Engine to handle complex topology reverse engineering with absolute stability.
